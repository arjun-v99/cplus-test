# CPLUS-Test App for Interview

All the main buisness logic are done using Javascript and AJAX.

# Installation
1. Run `composer install` command in your project directory to install the necessary packages to run the laravel framework
2. Run `php artisan serve` command in your project directory to run the project


# Requirements
1. Requires PHP 8.2 or higher
2. Additionally you'll need composer to install or update necessary packages
